# I51. Partial dynamical matrix (`atoms=`) x symmetry

Status: done for a subset that is a union of orbits; the refusal stays, sharpened, for any
other subset and for the streamed route.

## The number

The check is the entry's own, both halves of it: the subset's block against the whole cell's
block of the same symmetrised calculation, and the subset on the wedge against the subset on
the same closed sample run `nosym`. Measured on the merged head (`d54ac9c`, master 126d6ec
merged in) on D22, CPU, one core, one thread, by a harness doing exactly the computations of
the slow tests (`/l/ladovj1/review/incompat/I51/harness-t2.py`, log `t2-run1.log`; the nspin = 2
case and the controls `harness-t2b.py`, `t2-run2.log`). The commit after `d54ac9c` adds only the `nspin = 2` slow test (the same computation as `harness-t2b.py`) and this record, no code. Each figure is one run (the route is
deterministic on one core), at `tr2 = 1e-24` and a CG threshold of 1e-12 (`IDENTITY` in
`tests/regression/test_phonons.py`), max |difference| in Ry/bohr^2 on force-constant blocks of
0.18 to 0.23:

| cell | subset | against | difference |
|---|---|---|---|
| `alas-raman-wedge.in` (nc, 8 k) | `(0,)` / `(1,)` | whole wedge block | 6.293e-11 / 1.738e-10 |
| `alas-piezo-tiny-wedge.in` (US, 3 k) | `(0,)` / `(1,)` | whole wedge block | 5.051e-12 / 3.671e-10 |
| `alas-piezo-tiny-paw-wedge.in` (PAW, 3 k) | `(0,)` / `(1,)` | whole wedge block | 2.591e-12 / 3.556e-11 |
| `alas-raman-wedge.in` | `(0,)` | `(0,)` on `alas-raman.in` (`nosym`, 64 k) | 6.815e-10 |
| fluorite Si + 2 As, metal (inline in the test) | `(1, 2)` / `(0,)` | whole wedge block | 1.502e-11 / 1.666e-10 |
| `alas-raman-wedge.in` at `nspin = 2`, `tot_magnetization = 0` | `(0,)` / `(1,)` | whole wedge block | 6.291e-11 / 1.738e-10 |

The nc AlAs, US, PAW and fluorite figures are the old base's (`0feb4ee`, runs `run1` to `run3`
in the same directory) to every digit printed, so the merge of I1 to I48 moved none of them.

The residue is the loop's stop, not the symmetrisation. The two whole-cell routes on the same
AlAs pair (wedge against `nosym`) differ by **7.910e-10** at the same settings, so 2e-9 is the
floor the identity is held at (`CLOSED_SUBSET_TOLERANCE`). On the old base, at `tr2 = 1e-28`
and a CG threshold of 1e-14, the AlAs nc blocks fell to 3.9e-14 and 4.7e-13, so the residue
moves with the convergence (not re-run here: the nc blocks are bit-identical to that base at
`IDENTITY`). The negative controls, re-run on the merged head, the subset's in-loop `symdvscf`
switched off and then its `symdynph_gq` switched off, read **2.719e-3** and **5.346e-3**, six
orders above the bound, so a wrong symmetrisation could not pass. The fluorite cell is there
because its two As atoms are one orbit exchanged by the inversion, so the subset's own atom
table is a non-trivial permutation; `|D_12|` between them is 0.179, so the block is not two
independent ones.

The `nspin = 2` row is new with the merge: master's I2 opened the whole-k dynamical matrix
at `nspin = 2`, so a closed subset with symmetry now runs there too, and it was measured
rather than left to run unmeasured. The subset's symmetrisers act on each spin channel through
the same atom table, and the subset figures are the `nspin = 1` ones to the digits printed.
One thing seen beside it and **not** part of I51: the whole `nspin = 2` matrix of this
nonmagnetic cell differs from the whole `nspin = 1` one by **1.253e-6**, where I2's record has
1.6e-14 on unshifted `nosym` silicon. Both are whole-cell matrices, so the subset is not
involved; whether it is the wedge at `nspin = 2`, the starting magnetization or the fixed
counts was not looked at. The subset blocks at `nspin = 2` equal the `nspin = 1` ones to four digits while the whole matrix moves by 1.25e-6, so whatever moves it moves the subset block and its whole-cell reference together, which is the I51 identity holding. It is a question for I2 and the integrator, not a claim.

## What was missing

The entry's stated term, "a subset needs the stabiliser of the subset", was wrong. The k-set
is the wedge of the whole group, so completing the wedge sum for the response to atom `a`
along `i` reads `drho_{S^-1(a),j}` for every operation `S` of the whole group
(`symmetrize_atom_displacement_density`). Averaging over the subset's stabiliser would be an
average over a group the k-set was not reduced by, and wrong rather than slow. What is
available is the case where every operation maps the subset into itself, which is a union of
orbits, and then every symmetriser acts on the partial stack through the subset's own atom
table:

- `defuqumat/system/symmetry.py`: `orbit_closure` and `subset_atom_mapping` (new), the
  `(nsym, len(atoms))` table in the subset's own indices.
- `Calculation.symmetrize_atom_displacement(fields, atoms=None)` and
  `Calculation.symmetrize_atom_pair_tensor(tensors, atoms=None)` (`scf/driver.py`).
- `_symmetrize_modes` and `symmetrize_becsum_modes` (`response/phonon.py`) take `atoms`;
  PAW's `apply_atom_displacement` needed no change, since its `mapping` indexes only the
  displaced axis and the `becsum` atoms keep its own full table.
- `screening_loop`, `_whole_k` and `chunked_phonon.StreamedDisplacements.prepare` pass the
  subset through; `_phonons_of` applies `symdynph_gq` to the subset's block (before, it
  relied on the run being `nosym`).
- `_require_a_subsettable_regime` refuses with symmetry only a subset that is not closed,
  and names the smallest closed subset containing it (`atoms=(0, 1)` for silicon's
  `atoms=(0,)`, where half the operations exchange the sublattices).

Still refused, each with a test in `tests/unit/test_partial_phonon_refusals.py` (fast, guards
only, 5 tests in 5.5 s locally, 38 passed with no skip on D22 together with
`test_sibling_refusals.py` and `test_wedge_refusals.py`, `t2-unit.log`):

- a non-closed subset with symmetry (`test_a_subset_of_a_symmetrised_run_is_refused`, silicon;
  `test_half_an_orbit_is_refused_and_the_orbit_is_named`, fluorite's `atoms=(1,)`);
- a closed subset with symmetry on the streamed route (`dynamical_matrix`, after `_streams`
  decides the route; `test_a_closed_subset_on_the_streamed_route_is_refused`): the subset is
  threaded through `StreamedDisplacements.prepare` and the loop, but only the whole-k route
  was measured. Before this change that regime was refused by the general guard, so nothing
  that used to run is refused now. The merge put master's one-spin-channel check on the same
  route before it, the only conflict;
- the acoustic sum rule on a subset (`test_the_acoustic_sum_rule_is_still_refused_on_a_closed_subset`);
- a subset of a response walked a k-chunk at a time (I54, untouched).

The two refusal tests that sat in the slow file (`test_a_subset_of_a_symmetrised_run_is_refused`
and the streamed-route one) moved to the unit file, so the fast gate reaches them.

Trap check (`trap-check` list) on the diff from master: the two `np.asarray` are on the
host-side integer atom tables, never a tracer; the change is the wedge-completion
symmetrisation itself (trap "a response on a reduced k-set is symmetrised"), measured against
the `nosym` grid and with two negative controls that read 2.7e-3 and 5.3e-3 (trap "a check
whose null result cannot be told from a pass"); the identity is block by block, not an atom
sum (trap "a sum of N terms matching one total"). Nothing else applies: no new dtype, no `vmap`
over k, no `abs` or clamp.

Replace with:

> With symmetry, the phonons of a part of the atoms (`atoms=`) need a set of atoms that the
