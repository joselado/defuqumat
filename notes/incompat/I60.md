# I60. Transverse spin susceptibility (magnons) x PAW: partial (sized, refusal kept)

**No number; the refusal stands with a sharper message.** No D22 run was made for this item.

**What is missing, and where the entry was imprecise.** The entry said "the one-centre part of `B_xc`
in the kernel `B_xc/m`". Read against the Goldstone proof (`tddft/spinkernel.py` module docstring), the
term is not a correction to the grid kernel but a **channel**. The proof needs `H_up - H_dn = 2 B` for a
`B` the response is a matrix over. For an ultrasoft dataset the spin-dependent part of `D_ij` is
`int B_xc Q_ij`, the augmentation of the grid field, and the augmented matrix element already carries it
(why P93's ultrasoft nickel closes). A PAW run adds `(ddd_paw_up - ddd_paw_dn)/2` on the projectors, a
nonlocal operator `sum |beta_i> B_ij <beta_j|` exactly of the Hubbard channel's form (I61). So what is
needed is:

1. a projector channel `p = (a, i, j)` beside the plane waves, matrix element
   `conj(<beta_i|psi_up,k>) <beta_j|psi_dn,k+q>`, moment `(becsum_up - becsum_dn)_ji / Omega`, field
   `(ddd_paw_up - ddd_paw_dn)_ij / 2` (the I61 code in `transverse_response` and `goldstone_residual` is
   the template, with `wfcU` replaced by `vkb` and `ns` by `becsum`);
2. its kernel `K_{(ij),(kl)}`, which unlike the Hubbard one is not a constant: in the adiabatic local
   approximation it is the sphere integral of `B^1/m^1` against `phi_i phi_j phi_k phi_l` on
   `defuqumat/paw/`'s radial times angular grid, minus the pseudo partial waves' integral with the
   compensation charge `hat n` included in the pseudo one-centre density, and the node limit of
   `spinkernel.node_limit` on the sphere grid where `m^1` changes sign;
3. the check that the rotation argument fixes only `K m = B`, not `K` itself, so a kernel built as
   `diag(B_p / m_p)` would pass the identity and be unjustified: the Goldstone residual is necessary, not
   sufficient, and a second check (Elk's LAPW magnon on the same cell, T4) is needed.

Item 2 is the size: the one-centre transverse kernel on the sphere grid is a new object, a few hundred
lines with its own tests, and was not started inside this item's budget. I61's channel is its
prerequisite and is now in.
