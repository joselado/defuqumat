# I17. Symmetrised projected DOS x spin-orbit coupling

Status: done for a nonmagnetic spin-orbit run (`domag = .false.`); a magnetic spin-orbit
run stays refused.

## The number

The check is the wedge against the whole unshifted grid, on fcc platinum with spin-orbit
coupling, 2x2x2 unshifted, 48 operations: `tests/data/qe/pt-soc.in` and `pt-soc-paw.in`
(new, the committed `-nosym` twins with `nosym`/`noinv` removed and nothing else changed)
against `pt-soc-nosym.in` and `pt-soc-paw-nosym.in`. The quantity is the
occupation-weighted charge of each `|j m_j>` column, `sum_k sum_n f_nk |<phi_c|S|psi_nk>|^2`,
which is blind to the rotation inside a degenerate multiplet. One run on D22, CPU, one
core, `/l/ladovj1/w-inc-I17`, at commit bac9fda5 (the later commits change only test
bounds, comments and this record, so the number was not re-run at the final sha), log `/l/ladovj1/review/incompat/I17/run1.log`
(37 passed, none skipped, 202 s).

| | ultrasoft (`pt-soc`) | PAW (`pt-soc-paw`) |
|---|---|---|
| total energy, wedge against closed grid | 6.3e-11 Ry | 7.1e-10 Ry |
| column charges, symmetrised wedge against closed grid (this code) | 3.7e-7 | 5.2e-9 |
| column charges, symmetrised wedge against `projwfc.x` (`reference.<stem>.projwfc_up`, `lsym = .false.`, weighted with the closed run's occupations) | 1.7e-6 | 2.2e-6 |
| the closed grid's own distance from `projwfc.x` | 2.0e-6 | 2.2e-6 |
| unsymmetrised wedge against closed grid (the guard firing) | 7.5e-2 | 7.5e-2 |

So the symmetrised wedge sits on the closed grid to 4e-7 electrons, and its distance from
`projwfc.x` is the closed grid's own (the T1 side), while dropping the average costs
7.5e-2. The test asserts 1e-5, 1e-5 and > 1e-2:
`tests/regression/test_spinor_projection_symmetry.py::test_the_spin_orbit_wedge_reproduces_the_closed_grid`
(slow, both datasets).

The identity side, needing no ground state:
`tests/unit/test_projwfc.py::test_the_spin_orbit_rotation_keeps_each_j_shell_to_itself`
(1.1 s). On Pt's 48 operations, `l = 1, 2, 3`, the block between `j = l - 1/2` and
`j = l + 1/2` is 1.1e-15 and each shell's block is unitary to 1.8e-15 with `conj(U)`; with
`U`, `U^T` or `U^dagger` the cross block is 0.99, so the test tells the conventions apart.

What this does not test: the Kramers partner average (`sym_proj_so`'s `.not. domag`
pass, transcribed). Platinum has inversion, so a Kramers pair at one `k` already carries
equal `m_j` and `-m_j` weight once band-summed, and only a per-band projection could see the
average; no `lsym = .true.` `projwfc.x` reference is committed for that.

## What was missing, and where the entry was wrong

The entry says the missing term is `d_matrix_so`'s `D^j`, "a different matrix that
nothing here builds" (the guard's comment said it was "not reachable by relabelling").
That overstated it. `D^j` is a change of basis of the operator the noncollinear branch
already assembles: with `M_j` the `(2j+1, 2(2l+1))` spin-angle map
`pseudo/atomic.py:_spin_angle_matrix` builds the orbitals with, and
`A_s[(sigma, m), (sigma1, m1)] = D^l_s[m1, m] conj(U_s[sigma1, sigma])`,

    D^j_s = conj(M_j) A_s M_j^T

which is the same representation `d_matrix_so.f90` builds: it fits the `l` rotation of
the complex harmonics from random points on a sphere, multiplies by `conj(find_u)` and
changes basis with its Clebsch-Gordan matrices `Ul*C`; here the `l` rotation is the
real-harmonic one already validated and the basis change is `M_j`. No second guard
exists upstream: `workflows/pdos.py` and `Calculator.get_pdos` pass `symmetrize` through
to `atomic_projections` untouched. The code added is
`projwfc/projections.py:_spin_orbit_symmetry` (the tables), the shell key gaining `j`
(the two `j` of a fully-relativistic shell share `wfc`), and `ProjectionSymmetry.partner`
for the Kramers average. The guard in `atomic_projections` narrows from `lspinorb` to
`lspinorb and domag`; `_spin_orbit_symmetry` also refuses any operation with `t_rev = 1`.

Still refused: a magnetic spin-orbit run with symmetry. It needs no Kramers average and
QE's `m_j -> -m_j` swap under a time-reversed operation; no committed magnetic
spin-orbit cell keeps its symmetry, so no wedge of one has been compared with a closed
grid. That is a separate item (a wedge/nosym pair on a magnetic SOC cell, e.g. Fe or Pt
with a moment along a three-fold axis).
