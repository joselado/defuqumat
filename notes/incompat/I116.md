## What was missing, as found in the code

The entry says "an amplitude or staggered seed from a scalar field". The collinear seed
machinery was already there end to end: `seed.seeded_density` and `seed.seeded_becsum`
have an `nspin_mag = 2` branch, and `test_a_collinear_seed_reaches_the_state_the_tiled_loop_cannot`
runs it from a hand seed. What had no code was the scalar form of `seed_from_the_field`
(it asserts a `(3, *box)` field) and the driver branch, which is gated on `nspin_mag == 4`.
One thing the entry does not say: the sign of the reference matters. `v_up -= B`
(`add_bfield.f90:237-238`), so a positive `B` favours a positive `m`, and on a reference
whose moment converged down the seed `sign(B)` would put the moment against the field
everywhere. The seed written is therefore

    s(r) = sign(B(r)) * sign(M),   M = int m dr of the reference,

with `s = 1` (the identity) where `|B|` is below `FIELD_NODE_TOL` of its largest value, as
in the vector form, and skipped with a reason on a reference with no moment or a
compensated one (net below `SEED_NET_TOL` of the absolute).

**What it seeds is a domain state**, the reference reversed at full length wherever `B < 0`,
whatever `|B|` is. That is the physics question the check has to answer and the reason the
record does not lift the guard on a unit test: the hydrogen cell this would be measured on
has an antiferromagnet 3.085 mRy per cell below the tiled ferromagnet
(`test_a_collinear_seed_reaches_the_state_the_tiled_loop_cannot`), so under a weak
staggered field the tiled start may stay on the modulated ferromagnet while the seed lands
on the antiferromagnet, two fixed points of one functional. If so, the item's check ("the
converged state does not depend on the seed") fails as physics, and what the seed returns
is the state on the field's side, not the response.

Code (commit `c845e977`): `defuqumat/ultracell/seed.py:collinear_field_seed`, not called by
the driver. The lifted driver branch is in commit `8c7bf8e5` (`run_ultracell`, the `elif`
after the noncollinear field-seed block, and the `nspin_mag not in (2, 4)` guard), and was
removed again in `c845e977` so that no dead path stays behind the refusal. The refusal,
`run_ultracell`'s `seed_from_field` block, now reads "... a domain state, the reference
reversed where B < 0. The seed sign(B) sign(M) is written (seed.collinear_field_seed,
I116) but was not measured against the tiled start ...".

## The check that was not run

`notes/incompat/ultraseed-harness/i116.py`, launched by `run1.sh` after `setup.sh` (the D22
worktree `/l/ladovj1/w-inc-ultraseed`, run directory `/l/ladovj1/review/incompat/ultraseed/`).
Two-cell hydrogen (`HYDROGEN` of `tests/regression/test_ultracell.py`, moment 0.62 on the
folded `(4, 2, 2)` grid), `(2, 1, 1)` at kgrid `(2, 2, 2)`, `nbnd = 16`, field
`B cos(pi x)` at 0.002 and 0.02 Ry, `conv_thr` 1e-8 and 1e-10 (the convergence parameter),
three starts each: tiled (`seed_from_field=False`), the field's seed (handed over as
`seed_magnetization` through `collinear_field_seed` itself, since the driver refuses it),
and the wrong-sign domain start `-sign(B)` as the control a sign error would be. It prints
iterations, the first `dr2`, `E + E_field` per cell, the cell moments, `|m_Q|`, `m_0`, and
`max |rho - rho_tiled| / max rho_tiled`. What decides the item:

- if the field's arm and the tiled arm agree, the number is that density difference and
  the energy difference, falling from 1e-8 to 1e-10, with the field arm's first `dr2` far
  above the tiled one (so the seed was live) and the wrong-sign arm either reaching the
  same state or a higher `E + E_field` (what a sign error would cost);
- if they do not agree at 0.002 Ry, the two-basin finding is the number (the energy gap
  between the two converged states, and which one each start reached), and the seeded
  state should then be checked against the two-species supercell under the same field
  (`ANTIFERROMAGNET` with `starting_magnetization(2) = -0.8`, plus the field) on the `nbnd`
  ladder, as the hand-seeded test does.

## A question kept for the user

Whether a collinear run under a field should be seeded by default, as a noncollinear one
is since 2026-10-10. Kept as it was (the tiled start), because the noncollinear default
exists for a flat manifold the tiled start cannot leave (none in 1500 iterations), and a
collinear amplitude wave has a restoring force, so nothing measured says the tiled start is
slow there.
