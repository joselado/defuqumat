# I95. Sum-over-states `chi_0` x smearing on a gapped cell: done

**The number.** `si-epsilon-unshifted-nosym.in` (64 k-points, `ecutwfc = 18`), the density of
the fixed-occupation SCF (`conv_thr = 1e-12`) handed to a copy of the system with a Gaussian
smearing, so that only the sum over states moves; RPA `eps_M` with local fields
(`ecut_response = 2`, `nbnd = 16`, `eta = 0.01` Ry) at `omega` = 0.05, 0.1, 0.2, 0.3, 0.4 Ry,
trace over three, against the same run with `occupations = 'fixed'`. D22, CPU, one core, one
sample each (`review/incompat/chi0/h1-silicon.log`, worktree `w-inc-chi0`):

| `degauss` (Ry) | max abs `eps_M(smeared) - eps_M(fixed)` | without the Drude block | the Drude block alone |
|---|---|---|---|
| 0.02  | 8.444e-1 | 5.317e-1 | 6.327e-1 |
| 0.01  | 3.288e-2 | 7.714e-3 | 2.986e-2 |
| 0.005 | **2.196e-8** | 1.492e-9 | 2.138e-8 |

The fixed spectrum is of order 25 to 95 in modulus over the window. The convergence parameter is
`degauss`, and the discrepancy falls the way the smearing's tail across the gap predicts,
`exp(-(Delta/sigma)^2)`: the two successive pairs give `Delta` = 0.0208 Ry (from 0.02 to 0.01)
and 0.0218 Ry (from 0.01 to 0.005), the same distance from the Fermi level to the band edges
twice, about half of silicon's LDA gap on this mesh (that gap was not printed in the run). The
test asserts that the three fall in order and that the smallest is below 1e-6 (measured 2.2e-8).

**What the term switched off reads.** The item's missing term was the pair list, not the string
test: before this change the regime was refused outright, so there is no older number to compare
with. The Drude block's column says what the intraband half adds on the same states: it is the
largest part of the discrepancy at every `degauss` (the thermally excited carriers of a smeared
gapped cell really have a Drude response, which the fixed run has not), so the agreement at
`degauss = 0.005` is the tail being small, and the Drude block's own correctness is checked in
I96 against the conductivity, not here.

**What was missing, as found in the code.** The entry said the fix was the occupation test of
`_occupied_bands` in place of the string test of `_is_an_insulator`. That is too small: the
occupation test refuses any empty band carrying more than 1e-8 of filling, and silicon at
`degauss = 0.01` carries about `erfc(2.1)/2` = 1.5e-3 at the conduction band edge (estimated from
the `Delta` above, not printed), so only `degauss` below about 0.004 Ry would have passed. A
fixed-occupation run does not enter the new code at all (`smeared` is false, the rectangle and
the unmasked pair terms are the old ones), so every insulator number is untouched. What was missing is a pair list for fractional occupations:
`_band_windows` finds, per channel, the first band not full everywhere (`low`) and the first band
empty everywhere (`high`), within `genvchi0.f90`'s 1e-8, and `_pairs(low, high, nbnd)` lists
every `i < j` with `i < high` and `j >= low`, which is the old rectangle in the old order when
`low = high`. The weights are the smeared `wg`, as before. A window that reaches the top band is
refused with a message naming `nbnd`. The intraband half is I96's (`_drude_block`), shared.

**What stays refused**, each with a test: tetrahedron occupations (no smeared delta for the Drude
term), a scissors shift on a smeared run (there is no empty set to move), the bootstrap kernels
and the static residual on a smeared run in `run_absorption` (both need a finite static
`eps_M`), and the siblings on smeared cells: textured spinor, spiral, Hubbard `U`, ultrasoft
smeared, two-channel wedge, and a smeared `nspin = 2` run (`h10-chain-lsda`).

**User guide**, `docs/guide/optics.md`, the "Limits" note, first paragraph. Replace

> The absorption spectrum needs an insulator with fixed occupations. For a metal
> the sum over pairs of bands has no intraband term, so the Drude part of the
> response would be missing, and the code gives an error. A state where an empty
> band carries occupation at some k-point also gives an error.

with (I96 shares this sentence; this is the joint replacement)

> The absorption spectrum works with fixed occupations and with smearing. With smearing the sum
> runs over every band that is partly filled at some k-point, and the code adds the intraband
> (Drude) term, $\omega_p^2/(\omega + i\eta)^2$ on the head. We checked this term against the
> plasma frequency of the optical conductivity on aluminium, where the two agree to 4e-13. On
> silicon with a Gaussian smearing the spectrum moves onto the one with fixed occupations as
> `degauss` goes down: 0.84 at `degauss = 0.02`, 3e-2 at 0.01 and 2e-8 at 0.005. With smearing
> the `bootstrap` kernels and `static_residual=True` give an error, because the static
> dielectric constant of a metal is infinite. A scissors shift with smearing and tetrahedron
> occupations also give an error, and so does smearing with `nspin = 2`, because we have not
> checked that case.
