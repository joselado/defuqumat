## What was missing, as found in the code

The entry says "a per-site or staggered reference axis". **For a collinear antiferromagnet
neither is needed**: its moments are `m(r) = +-|m(r)| e`, so the existing pointwise
Rodrigues rotation `R(e -> s)` of `seed._turned` already turns the `+e` sublattice onto `s`
and the `-e` one onto `-s`, the antiferromagnet rigidly turned. The one missing piece was
`e` itself, which the net moment cannot give. It is now the principal eigenvector of the
second-moment tensor `M = int m m^T dr`, which is `+-e` for any such texture however exactly
the moments cancel. Two things come with it:

- **The sign of `e` is a convention that flips the whole seeded texture**
  (`R(-e -> s) m = -R(e -> s) m`). It is fixed as the sign of `m . e` at the first atom,
  in the unit cell's order, whose own grid point carries `|m . e|` above `SEED_NET_TOL` of
  the largest on the box (the same point `seeded_becsum` reads the seed at), so the seed
  `s` is the direction of the first magnetic atom's moment. Without the sites it refuses,
  since no other choice is reproducible.
- **A canted or noncoplanar compensated cell stays refused**: `M` must be rank one to
  `SEED_COLLINEAR_TOL = 1e-2` (`lambda_2 / lambda_1`), and four sublattices along `+-x` and
  `+-y` give 1.0. That is where the entry's "per-site" axis would be needed, and it is not
  written.

The field's own seed on a compensated reference stays skipped (`field_seed_axis`), since
turning the Neel vector onto the field is not how an antiferromagnet answers one (its Neel
vector goes perpendicular, the spin flop).

Code (commit `c845e977`): `defuqumat/ultracell/seed.py:neel_axis`, not called by the driver.
The lifted version (in commit `8c7bf8e5`) made `reference_axis` do this and passed
`sites`, the atoms' grid points `round(positions_crystal * cell_grid) % cell_grid`, from
`run_ultracell`; it also gave `_noncollinear_advice` a branch naming a Neel seed for a
compensated reference. Both were taken back in `c845e977`. The refusal in `reference_axis`
keeps its "residue of cancellation" wording and adds "A collinear antiferromagnet has a Neel
axis to turn about instead (seed.neel_axis, I117), which is written but not yet measured
against an explicit supercell, so it is not used".

## The check that was not run

`notes/incompat/ultraseed-harness/i117.py` (launched by `run1.sh`, which takes `3 8,16 yes`
and the supercell at `nbnd = 12`). The unit cell is two hydrogens 5.5 bohr apart along
`x` in an `(11, 5.5, 5.5)` bohr box, noncollinear, starting moments `+z` and `-z` (two
species, one UPF), which should converge to the collinear antiferromagnet; the harness
stops if `lambda_2 / lambda_1` is above `SEED_COLLINEAR_TOL`. Ultracell `(3, 1, 1)` at
kgrid `(1, 2, 2)` on the Kramers-closed default, seeded with the Neel vector turning 120
degrees per cell about `z`, `s(x) = (cos 2 pi x/3, sin 2 pi x/3, 0)`; the harness patches
`neel_axis` into the driver. The reference is the explicit six-atom supercell seeded per
species with what `R(+z -> s)` does to the two sublattices (atom A of cell `c` at
`angle2 = 120 c`, atom B at `120 (c + 1/2) + 180`, `angle1 = 90`). Compared, on the `nbnd`
ladder 8 and 16 (the convergence parameter): the energy per unit cell above the supercell,
which should be positive and fall, and the **site moments** (the magnetization integrated
over a 1.5 bohr sphere about each atom, one function on both boxes), whose largest error
should fall too. The site moments are what makes it a check of this term: the Fourier norm
the FM helix tests compare is blind to the global sign, so it would pass with the whole
texture reversed. The control is the same ultracell seeded with `-s`, the other sign
convention of the axis: the same energy and the site moments reversed (`site_error_reversed`
small, `site_error` near 2).
