# I12. Topological invariants x collinear `nspin = 2`

Status: done for the Berry curvature and the Chern number by the plaquette (`fhs`) route, one
channel at a time. Measured on D22 (CPU, one core, slot queue), worktree `/l/ladovj1/w-inc-I12`,
commit `759ebdd`, one run, 11 tests passed in 47 s.

## What was measured

Both numbers are single deterministic runs, not medians.

- **The entry's identity, nonmagnetic `nspin = 2` per channel against `nspin = 1`**, on
  `tests/data/qe/alas-berry.in` (zincblende, so the flux is nonzero plaquette by plaquette): the
  `nspin = 1` SCF and the `with_spin(2, tot_magnetization=0)` SCF, both at `conv_thr = 1e-10`, the
  4x4 plane at `k_3 = 0`, `nocc` left to the default (4 per channel from the density). Largest
  plaquette flux 4.144e-2; largest `|flux_s - flux_nspin1|` 9.691e-13 for both channels; Chern
  number 3.3e-17 in each channel. Test:
  `tests/regression/test_topology.py::test_a_nonmagnetic_channel_has_the_unpolarized_curvature`
  (slow), asserting 1e-6.
- **The check the entry's identity cannot make, that `spin` selects the channel it names**, on a
  magnet: triplet O2, `tests/data/qe/o2-fixed-lsda.in` (fixed occupations,
  `tot_magnetization = 2`), SCF at `conv_thr = 1e-12`, fixed-density states of each channel at
  the SCF's own k-point against `SCFResult.eigenvalues_by_spin[s]` over the occupied bands:
  largest deviation 6.58e-8 Ry (up, 7 bands) and 1.46e-7 Ry (down, 5 bands), against an exchange
  splitting of 0.131 Ry between the channels; the counts 7 and 5 come from the density, not from
  the caller. A source that read channel 0 whatever `spin` said fails the down channel by 0.131
  Ry. Test: `tests/regression/test_topology.py::test_each_collinear_channel_reproduces_its_own_scf_eigenvalues`
  (slow), asserting 1e-6.

The entry's check as written ("an integer") is a residue and could not fail: without spin-orbit
coupling each collinear channel's Hamiltonian is real in real space, `H_s(-k) = H_s(k)*`, so a
channel's Chern number is zero by symmetry in every collinear case, magnetic or not. What a channel
carries is its pointwise curvature, odd in `k`, which is why both checks above compare fields and
eigenvalues rather than the integer.

## What was missing

Not a per-channel definition. `DFTSource.states` already built both channels' Hamiltonians
(`Calculation.hamiltonian_from` returns one per channel) and diagonalised both; the guard covered
the hardcoded channel 0 in `eigenvalues[0]` (the gap check), `wavefunctions[0]`,
`energies=eigenvalues[0]` and `hamiltonians[0]`. The fix is a `spin` field on `DFTSource` (and
`run_berry_curvature(spin=...)`, which `Calculator.get_berry_curvature` and `get_chern` forward
by name) that keeps the one channel's Hamiltonian, and a default `nocc` at `nspin = 2` read off
what the channel's density integrates to (`nelup`/`neldw`), refused when that is not an integer
(a smeared magnet).

Still refused, each tested in `tests/unit/test_topology_spin_channels.py`:

- `nspin = 2` with no `spin` (the guard, its message now naming `spin = 0 or spin = 1`), a
  `spin` outside `{0, 1}`, and a `spin` at `nspin != 2`.
- The Kubo curvature per channel (`method = "kubo"`, `keep_velocity`): `VelocityOperator` builds
  every channel's `dH/dk` and `topology/kubo.py:121-125` hands it `psi[None]` and reads channel 0,
  so it would pair the down states with the up velocity.
- The Z2 (still `_require_spinors`), and the Berry-phase polarization and the orbital
  magnetization, which build their `DFTSource` without a channel and so still meet the guard.

## User guide

Page `docs/guide/topology.md`, the "Limits" note. Delete:

> A collinear run with `nspin = 2` gives an error, because it has two
> Hamiltonians and so two sets of invariants. For a magnet, you use the
> noncollinear run.

Replace with:

> A collinear run with `nspin = 2` has two Hamiltonians, one for each spin. So you
> give the spin channel, `spin=0` or `spin=1`, to `get_berry_curvature` and
> `get_chern`, and without it you get an error. The number of occupied bands is
> the number of electrons in that channel. Without spin-orbit coupling the Chern
> number of one channel is always zero, by time reversal inside the channel; the
> curvature at each k-point is not. The `kubo` method, the polarization and the
> orbital magnetization still give an error at `nspin = 2`.
