# I18. Site angular momenta x fully relativistic ultrasoft or PAW dataset

Status: done. The refusal in `defuqumat/projwfc/angular_momentum.py:_refuse_what_is_not_written`
is lifted for `noncolin` with `lspinorb`, which is the only way a fully relativistic augmented
dataset reaches it; the guard stays for anything else (unreachable today, since the projection's
own builder refuses a relativistic dataset without `lspinorb`). The gamma-only and spin-spiral
refusals beside it are untouched and their test (`tests/unit/test_sibling_refusals.py`) still
passes.

## The numbers

The metric, against `projwfc.x`. The site matrix is now built on the set `projwfc.x` projects
on, so its trace is `print_lowdin`'s charge, and the test holds every printed digit of it
(5e-5, the precision of the print) on both platinum datasets:

- ultrasoft, `tests/data/qe/pt-soc-nosym.in` against `tests/data/qe/reference.projwfc.pt-soc:673-675`:
  total 8.9858, s 0.5466, p 0.0000, d 8.4392;
- PAW, `tests/data/qe/pt-soc-paw-nosym.in` against `tests/data/qe/reference.projwfc.pt-soc-paw:712-714`:
  total 9.9880, s 0.5032, p 0.9944, d 8.4903.

Platinum is nonmagnetic, so `<L>` and `<S>` vanish there by Kramers, on the whole grid (`nosym`,
`noinv`) where nothing completes them, and are asserted below 1e-6. That zero would come out of
the wrong metric too, so it is not the check; the charges are.

The moments, on a magnet: tetragonal cobalt, `Co.rel-pbe-nd-rrkjus.UPF` (the cell of
`co-tetragonal-anisotropy-soc.in`, run self-consistently at `conv_thr = 1e-11`), one run each:

- with the coupling on and the moment along x and along y, which the C4 of the cell relates,
  `|<L>|` reads 0.117097947 in both (the same to the nine digits printed), `<L>` follows the C4
  and is parallel to `<S> = 0.890135`;
- at `soc_scale = 0`, `<L_z> = -1.014e-3` at `<S_z> = 0.891`, which is a residue and not
  round-off, for the reason in the next section;
- the A/B that names the residue: the same converged states projected on the same set with the
  two `j` chi of each shell replaced by their `(l+1, l)`-weighted average, which is the one radial
  function the operators assume, read `<L_z> = 1.66e-7`. With the coupling on the same average
  moves `|<L>|` from 0.11710 to 0.11914 (1.7 per cent).

There is no external reference for the moments by construction: `projwfc.x` has no `<L>`, and
Elk's `LSJ.OUT` is a muffin-tin decomposition, a different quantity.

## What was missing, and where the entry was wrong

The entry asked for the up/down doubling `_as_spinors` orthogonalised against
`_spinor_overlap`. That route is wrong on exactly the datasets the item is about, as
`notes/AUGMENTATION-NEXT.md` §1i already said: a fully relativistic file carries the two `j` of a
shell as two `PP_CHI` entries, so doubling each into up and down gives `4(2l+1)` columns where the
shell has `2(2l+1)` states (22 against 12 on `Pt.rel-pz-n-rrkjus`), and it could not reproduce
`projwfc.x`'s Löwdin charges, which are taken on the 12.

What was built instead is §1i's route. The site matrix is `(natomwfc, natomwfc)` on the
spin-angle functions `|l j m_j>`, orthonormalised against `_spinor_overlap` (so with `qq_so`),
which is the call `projwfc/projections.py` already makes and that `test_spinor_pdos.py` already
held to `projwfc.x`. Nothing new is derived for the basis. What is new is that the operators are
transformed rather than the basis: with `M` from `pseudo/atomic.py:_spin_angle_matrix`,
`L^{jmj} = M^* (L x 1) M^T` and `S^{jmj} = M^* (1 x sigma/2) M^T` over both `j` shells of one
`(atom, l, els label)` (`spin_angle_operators`, `_spin_angle_shells`, `_contract_spin_angle`).
`test_the_spin_angle_operators_are_l_and_s_in_another_basis` checks, for l = 0 to 3, that `J_z`
is diagonal with `m_j` in the order the channels label, `J^2 = j(j+1)`, `L^2 = l(l+1)`, both
algebras, and `L.S = [j(j+1) - l(l+1) - 3/4]/2`, all to 1e-12.

The two `j` of a shell are paired on adjacency, same atom, same `l` and the other `j`, not on
the `els` label: a file without `els` (the dojo convention) gets per-`l` counter labels, `3D` and
`4D` for one pair, and pairing on those would decompose each `j` alone and drop the cross-`j`
block without a word (`test_the_two_j_of_a_shell_are_paired_without_a_label`). The first two
commits paired on the label; the change came after the third D22 run and leaves every grouping
of the cobalt and platinum files as it was (adjacent, same label), so the numbers above stand,
and the two tests it adds need no SCF and passed locally. The guard that stays has its own
fire-and-silence test, `test_a_relativistic_augmented_dataset_without_lspinorb_is_still_refused`.

The one approximation is the cross-`j` block. `L` and `S` separately connect `j = l - 1/2` to
`j = l + 1/2` at equal `m_j`, and that matrix element carries the overlap of the two radial
functions, which the operators take as one. The 3D pair of the cobalt file overlaps to
`1 - 2.9e-5` and platinum's 5D pair to `1 - 7.9e-4`, and on cobalt the approximation is worth the
1.0e-3 quench residue and the 1.7 per cent above. `J = L + S` is diagonal in `j` and does not
need it.

One thing found on the way, not changed: the fully relativistic norm-conserving route (nickel,
`Ni.rel-pbe-nc-dojo`, the 0.0365 of `test_nickel_has_an_orbital_moment_when_spin_orbit_is_on`)
still builds the scalar set, which on such a file is also the over-complete doubling (each of
the two `j` chi of a shell gets `2l+1` real harmonics in each spin). The old guard message called
that regime exact; it is exact in the metric (`S = 1`) and over-complete in the basis. Moving it
onto the spin-angle route would move a validated number, so it is left for a decision.

> The site angular momenta give an error for a fully relativistic ultrasoft or PAW dataset,
> because the projection uses the scalar overlap for each spinor component and misses its spin
> off-diagonal part. A fully relativistic norm-conserving file is exact.

and replace it with

> For a fully relativistic ultrasoft or PAW dataset, the site angular momenta use the
> $|l\,j\,m_j\rangle$ orbitals of `projwfc.x`. So the charge on each atom is the Löwdin charge

> $\langle L\rangle$ and $\langle S\rangle$ treat them as one function. On cobalt with the
> coupling switched off, this gives $|\langle L\rangle| = 1\times10^{-3}\,\hbar$, where the exact
> value is zero. With the coupling on, it changes $\langle L\rangle$ by 1.7 per cent.

The rest of that paragraph (spin spiral, `K_POINTS gamma`, the reduced k-set) stays.
