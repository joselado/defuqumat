# I14. Berry-phase finite field (`lelfield`) x `nspin = 2`: done

**The number.** `tests/regression/test_berryfield.py::test_a_nonmagnetic_spin_regime_is_the_unpolarized_field[nspin=2, ...]`,
run on D22 (CPU, one core, `w-inc-finitefield-v2`, log `review/incompat/finitefield/nspin2-2.log`), one sample:
the pw_electric chain on Si8 (63 k-points as 9 strings of 7, `efield = 0.001`, `conv_thr = 1e-11`) run at
`nspin = 2, tot_magnetization = 0` against the same chain at `nspin = 1`. What the field does to the total,
`E(E) - E(0)` of each regime's own chain, agrees to **1.1e-10 Ry** (asserted at 1e-9); `el_pol` to **2.3e-7**
Ry a.u. (asserted at 1e-6, beside the 1.6e-5 by which `pw.x`'s own value moves between its last two
iterations); `ion_pol` exactly; and both force routes (autodiff and analytic) match `pw.x`'s
`reference.out.si8-lelfield` forces at the file's 1e-6 Ry/bohr. Seven iterations, as at `nspin = 1`.

The absolute totals differ by **7.44e-7 Ry at zero field and 7.44e-7 with it**: that offset is the
spin-polarized PBE at zero polarization against the unpolarized one, present before the field is switched
on, and is the reason the identity is written on `E(E) - E(0)` rather than on the total. It is not this
item's and is recorded here so nobody reads it as the field's.

**What was missing**, as found in the code. The entry's "one string set per channel" was right and
incomplete. `BerryFieldSetup.term`, `enthalpy` and `string_phases` read `wavefunctions[0]` only and the
driver put that one channel's operator on both channels' Hamiltonians; the occupied count was
`nelec/2` for every channel; and `el_pol` carried the factor 2 that `c_phase_field.f90:612` applies only at
`nspin = 1`. Now each channel gets its own operator from its own states, its count is `NINT(nelup)` /
`NINT(neldw)` (fixed LSDA is always the two-count branch here), and the energy sums the channels' string
averages with no factor 2. `fact` is unchanged: the factor 2 the energy loses is the one the k weight
`w_k = 1/nk` loses, which `tests/unit/test_berryfield.py::test_each_channel_is_the_derivative_of_its_own_energy`
asserts with `jax.grad` on two channels carrying different states.

**What stays refused**, with its test: `nelup /= neldw` (`test_unequal_channels_are_refused`). `pw.x`
builds the phase on `NINT(nelec/2)` bands in each channel whatever the channel holds (`l_cal` in
`c_phase_field.f90` and `h_epsi_her_set.f90:221` reads `f_inp` only for `occupations = 'from_input'`), so
there is no `pw.x` number for a magnet and none was measured here; a magnet would need a `from_input` run
of `pw.x` (T4).

**User guide**, `docs/guide/electric-field.md`, the "Limits" note, second paragraph. Replace

> It gives an error for `nspin = 2` and spinors.

with

> It works for `nspin = 2` when the two channels hold the same number of electrons
> (`tot_magnetization = 0`), and for a spinor run without spin-orbit coupling and without a
> magnetization; it gives an error for a magnet, for spin-orbit coupling and for a magnetized spinor,
> because `pw.x` counts the occupied bands of a channel as `nelec/2` and so has no number to check
> against.

(the same sentence serves I15).
