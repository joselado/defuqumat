# I61. Transverse spin susceptibility (magnons) x DFT+U: done (simplified functional)

**The number.** The Goldstone identity `X_0(q = 0, 0) B = m` over the plane waves and the new Hubbard
channel, on `tests/data/qe/h-fcc-magnon-ldau.in` (fcc H, `U H-1s 2.0` eV, `nbnd = 30`,
`ecut_response = 12`; D22, `w-inc-magnon-v3`, log `review/incompat/magnon/hubbard-1.log`, one sample):
relative residual **0.00473** with the channel against **0.197** from the plane waves alone, the latter
being what the code would have computed with the refusal simply removed. `lambda_max(X_0 K)` reads
**1.0143** with the channel and 0.818 without. The channel's own `K m = B` holds to round-off on the
converged `ns` (`B_U = -0.028237`, `K m_U = -0.028237`). At `q = (0, 0, 1/4)` `lambda_max` is 1.0597
against 0.8312, so the channel moves finite-`q` magnons by the same order. The zero-U cell at the same
settings reads 0.0057. The slow test's body passed on D22 (`slowbodies-1.log`).

**What was missing.** The entry said "the Hubbard term's response to `m` in the enhancement; a nonlocal
piece". That is right, and the piece is a channel, not a correction to `F`: the simplified functional adds
`sum |phi_a> (v_up - v_dn)_ac <phi_c|` to `H_up - H_dn`, so the identity's proof needs the exchange field
expanded over the operators `O_p = |phi_a><phi_c|` of each correlated block as well as over the plane
waves. Implemented: `spinchi0.hubbard_pairs` (the `(slot, a, c)` of every block entry, both orderings, from
`HubbardSetup.block_indices`); `transverse_response` appends the matrix elements
`conj(<phi_a|psi_up,k>) <phi_c|psi_dn,k+q>` after the sphere's, with the same `2/Omega`, the projectors at
`k + q` passed as chunk arguments; `spinkernel.hubbard_moment` (`(ns_up - ns_dn)_ca / Omega`),
`hubbard_field` (`(v_up - v_dn)_ac / 2` from `hubbard_potential`), `hubbard_kernel`
(`-(U_eff + J0) Omega / 2` per slot, the rotation argument applied to a field linear in the block's moment),
`response_kernel` (block diagonal, checks `K m = B` before use), and `goldstone_residual(..., ns=)`. The
workflow takes `ns` (forwarded by the `Calculator`).

A limit of the check, stated: one s shell gives a one-entry channel, so it cannot see an `(a, c)` against
`(c, a)` slip in a d shell. The index order was derived from the docstring definitions
(`ns_ac = sum w conj(<phi_a|psi>) <phi_c|psi>`, `HubbardTerm` applying `sum v_ac |phi_a><phi_c|`) and is
symmetric on any collinear `ns` at `q = 0`; a d-shell cell at finite `q` would test it.

**What stays refused**, each with a test in `tests/unit/test_magnon_regimes.py`: the full functional,
`lda_plus_u_kind = 1` (`test_the_full_functional_is_refused`, `feo-kind1-J.in`), `Hubbard_beta`
(`test_hubbard_beta_is_refused`; a field on the block by hand), a `TENSOR_MOMENTS` constraint (message
only, no committed input), and a Hubbard U on a spinor run (I59's guard). The intersite `V` is refused at
input already.
