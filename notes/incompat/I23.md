# I23. Berry-phase polarization and orbital magnetization x spin spiral: blocked

No number. The refusals stay, each sharpened, and each now has a test that
fires it.

**Polarization** (`workflows/polarization.py:run_polarization`). The entry's
term ("the overlap between neighbouring k on two spheres is not one gather") is
the second half. The first is that each string's states come from an NSCF at
new k-points, which needs `Calculation.at_kpoints` on a spiral, and that is
refused ("a new k-list for a spiral means a new calculation"). With it, the
overlap is two gathers by Miller index, one per component on its own sphere
(`k + q/2` against `k + b + q/2`, and the same for the down component), and the
string phase is the determinant of their sum. The check would be the NiI
supercell's polarization along `z` against the spiral's, which `I22`'s supercell
helpers already set up. Not attempted tonight. Test:
`tests/unit/test_polarization_machinery.py::test_a_spin_spiral_is_refused_by_name`
(existing, still passes against the new message).

**Orbital magnetization** (`workflows/orbital_magnetization.py`). The entry is
wrong about what is missing: this is not a gather. The quantity needs
spin-orbit coupling, which a spiral refuses permanently (it breaks the
generalized Bloch theorem, `PLAN.md` P19, and Elk refuses it too), and at
`soc_scale = 0` a flat spiral's orbital magnetization is zero by the combined
symmetry of time reversal and a half turn of the spins about an axis in the
spiral plane. So the only identity left is a symmetry zero, which is a residue,
not a check. This half of the item is T5-like: refuse permanently, and the
commensurate supercell with spin-orbit coupling is the calculation that carries
it. Test added:
`tests/unit/test_orbital_magnetization.py::test_a_spin_spiral_is_refused_by_name`.
