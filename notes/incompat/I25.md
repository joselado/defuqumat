# I25. STM image, STS and tunnelling maps x spin spiral: partial (the charge image is done)

**Measured.** The constant-height charge image of the NiI spiral at
`q = b3/4`, on the plane `x = 0.6` (crystal) spanning one unit cell along the
chain, 12 x 12 points, tip at the spiral's Fermi level, against the supercell's
image on the same points (the first quarter of its `a3`): **2.9e-9 relative**
(5.1e-10 on a largest value of 0.173). One D22 run
(`review/incompat/spiral/v3-nii.log`). Test:
`tests/regression/test_spiral_supercell.py::test_the_spiral_charge_image_is_the_supercell_image`
(slow), and `tests/unit/test_stm_machinery.py::test_the_charge_image_of_a_spin_spiral_passes`.

**Where the entry was wrong.** It says `|psi(r)|^2` of a two-sphere state "is
not the lattice-periodic object this sum builds". It is lattice periodic:
`|U_up|^2 + |U_dn|^2`, and the image is built from
`Calculation.density(wavefunctions, tip weights)`, which on a spiral already
transforms each component on its own sphere. So the charge image needed no new
term, only the refusal narrowed (`charge_image=True` from `run_stm` without a
`spin`). The image's `values_by_spin` is not reported on a spiral, since the
transverse pair is in the frame that turns with `q`.

**Still refused** (`workflows/stm.py:_refuse_what_has_no_fermi_level`):

- a spin-resolved image: the laboratory transverse moment turns by `q . R`
  from cell to cell, so a spin projection is not a function on one cell's
  plane (a supercell is the only way);
- the tunnelling spectrum (`run_sts`) and both tunnelling maps
  (`workflows/transport.py`): they sample `psi(r)` on one `k + G` list
  (`basis/sample.py:sample_wavefunctions`), where a spiral's components are on
  `k + q/2 + G` and `k - q/2 + G`; the charge spectrum is lattice periodic and
  would need that sampler per component;
- a denser k-set (`grid=`), which needs `at_kpoints` on a spiral (see I22).

**User guide**, `docs/guide/stm.md`, Limits: replace "The STM image gives an
error for a spin spiral, because its two spinor components live on different
plane-wave spheres and $|\psi(\mathbf r)|^2$ is then not periodic in the cell."
with "The STM image of a spin spiral works for the charge, which is periodic in
the cell. A spin-resolved image of a spiral gives an error, because the moment
turns from cell to cell, and so does a denser `grid`." The second sentence
("A spin spiral, a fixed `tot_magnetization` and an applied field give an
error, as for the image.") becomes "A spin spiral gives an error, because the
spectrum samples each state on one plane-wave list, and so do a fixed
`tot_magnetization` and an applied field, as for the image."
