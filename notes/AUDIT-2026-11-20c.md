# What twenty more readers found, third round of 2026-11-20

## What this is

The first round of 2026-11-20 (`notes/AUDIT-2026-11-20.md`) read the code written since the
audit of 2026-11-15, and the second round (`notes/AUDIT-2026-11-20b.md`) read the core that
the earlier readers left open: the first third of the driver, the mixing, the hot path, the
eigensolvers, PAW, the response at Gamma, forces and stress, the noncollinear XC and the
inputs. This third round reads what neither covered, in 20 slices: 17 by subsystem
(topology, Wannier, real time, the ultracell, optics, strain and the third derivatives,
DFT+U, projections and bands, STM and diffraction, van der Waals with the input and output
files, symmetry and k-points, batching and pools, the whole `Calculator`, the middle and
last thirds of the driver, the magnetism tail, and phonons at q with the electron-phonon
coupling) and 3 across the package (the user guide against the code, tests that cannot
fail, and a search for the recurring traps and for recompiles).

One reader per slice, all on Opus 5.5, looking for bugs and optimizations, quoting the code
path and naming an input that reaches it without being refused upstream. There was no
skeptic stage, so the severity and the confidence are the reader's own.

Nothing was run, by the user's instruction. The 2508 shell commands in the readers'
transcripts were searched afterwards for a command that starts with `python`, `pytest`,
`ssh` or `tools/`. The two matches are shell variable assignments that name a Python
identifier, and none executes code.

The branch moved under the readers, since fixes of the first round were being committed at
the same time. The readers started at `14f1d06b`, `18254408`, `262b5595`, `43c57b68`, `531a7f50`, `ad311385`, and each says
in its slice summary whether its files changed while it read. If a line no longer holds what
an entry describes, grep for the symbol.

## The count

87 findings: 3 of high severity, 26 medium and 58 low. By kind, 42 bugs,
21 optimizations and 24 mismatches between the code and its text. No two readers reported
the same defect.

### #21: no refusal of a force or stress under a fixed tensor moment
